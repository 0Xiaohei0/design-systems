# STRATOS

Sci-fi FUI signal-overlay kit: dense instrument readouts on black glass, one
ink (#f4f2ee) plus one hot orange (#ff6a00), flat marks only - no glow, no
blur, no radius, no gradient fades.

Status: **Exploration**. Direction pinned by the client from a reference sheet.

## Contents

- `DESIGN.md` - the spec: tokens, type voices, naming grammar, motif
  vocabulary, component states, do/don't.
- `css/stratos-core.css` - tokens, primitives, marks, and components.
- `index.html` - the catalog: hero overlay cluster, foundations, marks,
  components, and a full telemetry console composition.

All demo data is synthetic. See `DESIGN.md` for the authoritative rules.
