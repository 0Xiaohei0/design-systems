# Sprout

Cozy farm-game pixel UI kit. Every control is a hand-baked game prop - biscuit
buttons, wooden plank sliders, painted leaf signs with curling tendrils - drawn
on a 3px pixel grid on a warm matcha board. No border-radius anywhere: corners
are clip-path step polygons, depth is a one-unit bevel, icons are integer SVG
rects, motion is `steps()` only.

**Status: Exploration.**

**Credit:** an homage to the *Sprout Lands* UI asset pack by Cup Nooble. This is
an original CSS/SVG recreation of the style - the assets themselves were not
copied; every sprite here is redrawn from scratch as inline rect-art.

## Contents

- `DESIGN.md` - the durable spec: tokens, the pixel-construction rule, type
  voices, motif vocabulary, component states, motion, contrast floor.
- `css/sprout-core.css` - tokens, primitives, and all components (plain CSS).
- `index.html` - the catalog: the asset-sheet hero, foundations, construction
  anatomy, every piece with states, and a seed-shop composition.
- `css/portal-card.css` - portal entrance card (owned by the portal task).

Start with `DESIGN.md`; the catalog page demonstrates everything it specifies.
