# Chaguan (茶馆)

A neo-Chinese teahouse mini-app system: storefront task UI (order, pick up,
member) wearing literati ink-painting clothes - brush calligraphy shop names,
solid-ink illustrations over a gold sun disc, vermilion seals, deep-coffee
blocks, and one olive-green variant, all kept instantly scannable.

**Status:** Exploration.

**Homage:** style homage to Lulu's mini-program design sharing sheet (eight
teahouse / dessert / tavern storefront screens pinned on a caramel mount).
All shops, dishes, prices, and balances here are synthetic.

## Contents

- `DESIGN.md` - the durable spec: tokens, type voices, motif vocabulary,
  component states, the olive variant rule, do/don't.
- `css/chaguan-core.css` - tokens, primitives, components, catalog layout.
- `index.html` - the catalog sheet: bilingual masthead, two complete
  phone-frame storefronts (cream teahouse + olive dessert variant),
  foundations, the six brush illustrations, motifs, component states, and a
  full ordering screen.
- `css/portal-card.css` - portal entrance card (owned by the portal task).

Start with `DESIGN.md`, then open `index.html` through the playground dev
server.
