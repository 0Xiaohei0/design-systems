# ENJOY

Cozy retro-desktop design system: personal computing as a warm hobby. Every
element is a window or desk object - 2px ink outlines, cream fills, hard offset
shadows, one mono typeface - floating over a sunny cream desk with big lazy
pastel-aqua waves. One saturated blue field is reserved for the player's lyrics
pane.

**Status:** Exploration (client-pinned direction from a ricing-screenshot
reference).

## Contents

- `DESIGN.md` - the durable spec: tokens, one-typeface rule, window anatomy,
  motif vocabulary, component states, do/don't.
- `css/enjoy-core.css` - tokens, primitives, and components. Plain CSS.
- `index.html` - the catalog page, presented as the desktop itself: menu bar,
  clock widget, browser window, desktop icons, foundations, motifs, component
  states, and the full player window.
- `css/portal-card.css` - portal entrance card (owned by the portal task).

Start with `DESIGN.md`; the catalog page is the visual source of truth.
