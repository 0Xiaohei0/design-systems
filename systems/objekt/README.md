# OBJEKT

Brutalist industrial sticker system. Every UI element is a printed label:
stickers, stamps, barcodes, serial plates and spec sheets on paper stock, laid
on a concrete-gray sheet inside a black press frame. Four stocks (black, kraft,
steel, bone) and their inks are the entire palette; depth exists only as the
hard offset shadow of a lifted sticker.

Status: **Exploration**.

## In this folder

- `DESIGN.md` - the durable spec: tokens, stocks and inks, type voices, motif
  vocabulary, component rules and states, do/don't list. Read this first.
- `css/objekt-core.css` - tokens plus all primitives and components, plain CSS.
- `index.html` - the catalog sheet: hero strip set, stocks, type voices,
  motifs, components with every state, and one assembled product spec sheet.
