設計系統 Design System

新聞SHIMBUN

报纸编辑部式的界面语言：暖纸底、一抹朱红套印、超大紧凑标题、单色细线、 等宽字体标注。字负责说话，装饰只剩下线条、眉题和一道渐隐。

开读之前记住两件事。颜色的名字是角色，不是色相——深色主题下 --ink 是暖白，--bg 是暖黑，名字依然成立。 还有朱红是声音，青是工具：朱红只用来让人抬头，青只用来标记可操作的东西， 两者都不是装饰色。

12色彩令牌 ROLE TOKENS

实现前先读这段 / Read this first

  1. 这些值就是系统本身。下面每个数字都存在于 css/tokens.css，直接用，不要另起一套。
  2. 饱和色只有两个——朱红和青。除此之外整套语言里没有第三个彩色，加一个就等于把「朱红＝抬头」这个约定作废。
  3. 圆角封顶 6px，药丸除外。印刷品不圆，这条是系统的骨相而不是口味。
  4. 两套纸都要画。深色不是自动推导出来的，是手写的；只检查一套不会有任何东西提醒你。
  5. 阴影是稀缺品。全系统只有弹窗和卡片 hover 用得起，其余一律平放。
  6. 不要新造缓动曲线。两个时长、一条 ease，够了。

12 role tokens

每张色卡左边是白天的纸，右边是夜里的纸，两套同时在场。 浅色是暖纸灰，深色是暖纸的夜晚——不是冷黑。中性色里没有一个是纯黑或纯白。

不随主题翻转的三个 / Theme-independent

TokenValue为什么不翻
--media-scrimblack 0.62 → 0压在图像底部的渐隐。图像不会跟着主题翻转，所以压在它上面的东西也不能翻——翻了就会在没动过的背景上反色。
--seq-chiprgba(8,10,14,.82)序号签的底。同样坐在图像上，同样必须钉死。
--scrimrgba(9,11,15,.76)弹窗遮罩。它的职责是压暗底下的一切，本来就与主题无关。
对比度是闸门，不是偏好。正文必须过 AA 4.5:1，提示块做到 7:1。 浅色的 --muted 之所以是 #5E625F 这样一个偏暗的值， 就是为了在暖纸上刚好过线——把它调亮一点会好看，然后整页次级文字全部失效。

拒绝清单 / Refusals

  • 不加渐变——除了图像底部那道为了看清字的黑渐隐。
  • 不加阴影——除了弹窗那一记，和卡片 hover 的轻浮。
  • 不用纯黑纯白做浅色底——每个中性色都是暖的。
  • 圆角不超过 6px——药丸除外；这里不卖可爱。
  • 能用眉题和线解决的，不用图标和插画装饰。
两级圆角之间只差 2px，这是故意的。4px 和 6px 在视觉上几乎分不出， 分得出的是它们和 999px 药丸之间的鸿沟。系统只需要「方」和「圆」两种态度， 中间那些温吞的档位一个都不要。

Motion动效

2 durations

安静。两个时长、一条曲线，只有 transform、opacity 和颜色会动。

TokenValue用在哪
--t-hover0.18s卡片浮起、药丸反色、按钮换底。看得最多，所以压得最短。
--t-zoom0.35s弹窗进场。唯一允许慢下来的时刻。
--easeease全系统唯一的曲线。不要再引入第二条。
lifttranslateY(-3px)卡片 hover。整套语言里最大的一次位移。
3px 是上限而不是起点。印刷品不会浮起来；这 3px 已经是对纸的最大让步， 再多一点，卡片就从「一张纸」变成「一个控件」，整套材质的说服力跟着没了。 prefers-reduced-motion 下全部归零,页面依旧完整。

解剖 / Anatomy

部件做法为什么是这样
报名栏1fr / auto标题左、巨型数字右，底部 2px 粗线。数字是配重，不是信息——它让紧排的标题不至于把版面压偏。
眉题kicker整页唯一先出现的朱红。它先说话，标题才接得上。
卡片栅格--grid-gap间隙跟着页边距一起流动，所以窄屏不会出现「边距很小但卡片间很宽」的错位。
图像框16/9 + scrim渐隐只为让戳记可读而存在，不是风格。没有压字的地方就不该有渐隐。
强调签tag hot一屏最多一处。第二处出现，读者就不知道该先看哪个了。
分隔2px rule分区靠线断开而不是靠留白，所以卡片可以贴得比直觉更紧。
注意这一段不是什么：它不是把某个产品的页面换掉文字。 占位内容特意选了印刷业的词——活字、校样、版面——因为它们对任何读者都不构成「这套系统是做某某的」的暗示。 读者带走的是结构。

Rules准则

拒绝比允许重要

应该 / Do

  • 让朱红只负责抬头：眉题、强调签。一屏最多一两处。
  • 让青只负责可操作：聚焦环、提示块。它是工具色，不是第二个装饰色。
  • 用 2px 粗线分段，用细线分行。两种线各有一份职责。
  • 两套纸都手写，并且用顶栏的切换按钮真的看一遍。
  • 元信息一律交给等宽：编号、计数、标签、日期。
  • 中性色保持暖调。冷灰放在这张纸上会显脏。

不要 / Do not

  • 加第三个饱和色。加了就等于宣布朱红不再特殊。
  • 加渐变——除了图像底部那道为了让字可读的渐隐。
  • 加阴影——除了弹窗，和卡片 hover 的 3px。
  • 用纯黑或纯白做浅色底。
  • 把圆角开到 6px 以上，药丸除外。
  • 用色相给令牌命名。深色主题一翻，名字就变成假话。
